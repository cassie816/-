# 每日粉丝增量看板

一个轻量的静态单页小工具，用来：记录每日粉丝总数与点赞总数、自动计算当日涨粉、显示折线图和表格，并支持数据导入/导出。

主要功能
- 输入/更新：按日期填写“粉丝总数”和“点赞总数”。
- 本地保存：使用 `localStorage` 持久化数据。
- 表格：显示按日期排序的数据行，支持按列排序（包括按“当日涨粉”排序）。
- 筛选：按开始/结束日期筛选与关键词搜索（支持日期/粉丝/点赞）。
- 图表：折线图展示每日涨粉（基于时间序列计算）。
- 导出/导入：支持导出 JSON、导出 CSV（含 UTF-8 BOM，兼容 Excel），并支持从 JSON 导入。

快速预览

在项目目录运行静态服务器后打开页面：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

使用说明

- 添加/更新数据：在顶部表单填写日期、粉丝、点赞，点击“添加 / 更新”。已有同日期记录会被更新。
- 排序：点击表头（日期/粉丝/点赞/当日涨粉）切换排序方向。
- 筛选：使用“开始日期/结束日期/搜索”限制显示数据，点击“重置筛选”恢复全部数据。
- 删除：表格每行右侧有“删除”按钮，按日期删除记录。
- 导出 JSON：点击“导出 JSON”可下载当前完整数据（不受筛选影响）。
- 导出 CSV：点击“导出 CSV”会在当前筛选/排序下导出 CSV 文件（包含 UTF-8 BOM，便于在 Excel 中直接打开且不出现乱码）。已生成的文件名为 `fan-data.csv`（示例已保存到项目根目录）。
- 导入 JSON：使用“Choose File”选择一个符合格式的 JSON 文件（数组形式），将覆盖当前数据并刷新视图。

关于 CSV 与 Excel 兼容性

- 导出的 CSV 在前面添加了 UTF-8 BOM（`\uFEFF`），以避免 Excel 在某些语言环境中出现编码错误或问号替换。
- 如果你需要 Excel 直接打开，请在导出后用 Excel 打开或先在文件管理器中右键选择“用 Excel 打开”。

开发与调试

- 核心文件：
	- `index.html`：页面结构与控件（日期输入、按钮、表格、图表）。
	- `style.css`：样式（简单响应式布局）。
	- `app.js`：业务逻辑（读取/保存 `localStorage`、渲染表格、计算 delta、Chart.js 绘图、导入/导出）。
- 如果需要调试图表数据，可以在浏览器控制台访问 `window.chart`（开发时已暴露以便查看数据）。

自动化测试（端到端）

项目包含一个简单的端到端测试脚本，使用 Python Playwright 驱动浏览器验证核心流程（添加/渲染/排序/导出 CSV）。

准备与运行：

```bash
# 安装依赖并运行测试脚本（会启动本地静态服务器）
./run_tests.sh

# 如果你的网络/证书环境阻止 Playwright 下载浏览器二进制，可以跳过下载并使用系统已安装的 Chrome/Chromium：
SKIP_BROWSER_INSTALL=1 ./run_tests.sh
```

脚本说明：
- `requirements.txt`：列出 Python 依赖（Playwright）。
- `tests/e2e_test.py`：测试脚本，启动浏览器（headless）并检查页面要点。
- `run_tests.sh`：安装依赖、下载浏览器二进制、启动本地服务器并运行测试。
